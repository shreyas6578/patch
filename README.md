# Patch Management System

## Overview

Previously, patch deployment details were manually maintained in **Google Sheets**, which made it difficult to track patch versions, deployment environments, and history efficiently.

To solve this problem, the **Patch Management System** was developed to centrally manage and track patch information. The system allows users to **upload, store, download, and maintain patch details**, and track where patches are deployed across different environments such as **Client, UAT, and Live (Production)**.

This application improves **organization, traceability, and reliability of patch deployment processes** compared to manual spreadsheet management.

---

## Features

- Upload and store patch files
- Maintain patch details and version information
- Download patches when required
- Track deployment environment (Client / UAT / Live)
- Maintain patch deployment history
- Store patch metadata in database instead of manual spreadsheets

---

## Problem Solved

Before this system:

- Patch data was stored manually in **Google Sheets**
- Difficult to track patch versions
- Hard to identify where patches were deployed
- No proper deployment history management

With this system:

- Patch data is stored in a **centralized database**
- Easy to track **deployment environments**
- Faster **patch retrieval and download**
- Improved **deployment tracking and management**
